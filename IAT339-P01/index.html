P01 - QQ Tea Style Guide

A style guide for QQ Tea, a fictional online bubble tea shop

Interactive Elements Text Elements Combined Elements Product Listing Template Checkout Template Citations

Interactive Elements

In-text link

Sample code:

<p>
  Craving something new? Explore our
  <a href="#seasonal">seasonal tea collection</a>
</p>

Rendered element:

Craving something new? Explore our seasonal tea collection

Navigation Link

CSS selector:

.button-nav

Sample code:

<a href="#" class="button-nav">Menu</a>

Rendered element:

Menu

Submit/Reset Buttons

Sample code:

<button type="submit">Add to Cart</button>
<button type="reset">Start Over</button>

Rendered element:

Text Input Field with Label

Sample code:

<label for="cup-name">Name for your cup:</label>
<input type="text" id="cup-name" placeholder="Your name">

Rendered element:

Radio Button with Label

Sample code:

<input type="radio" id="half-sweet" value="50">
<label for="half-sweet">50% Sweet</label>
